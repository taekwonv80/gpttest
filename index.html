스마트플레이스 내부 통계는 현재 자동화 범위에서 제외합니다.

공개 API가 제공되지 않는 플레이스 유입, 리뷰, 유입키워드 등의 데이터는 임의 수집하지 않습니다. 공식 연동 수단이 생기면 추가합니다.

SECURITY RULE

API 키는 화면에 저장하지 않습니다.

네이버·Slack 키는 GitHub Secrets 또는 서버 환경변수에만 저장하고, 공개되는 HTML과 JavaScript에는 포함하지 않습니다.
